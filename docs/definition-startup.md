# Définition : qu'est-ce qu'une startup guinéenne ?

> Statut : **version 0.1, à valider** (phase 1 de la roadmap). Toute modification de cette définition est tracée dans l'historique Git.

## Périmètre géographique

Une entreprise entre dans le registre si **au moins une** de ces conditions est remplie :

1. Elle est immatriculée en Guinée.
2. Elle a été fondée par au moins une personne de nationalité ou d'origine guinéenne **et** exerce une activité réelle sur le marché guinéen.
3. Son marché principal est la Guinée, même si l'entité juridique est immatriculée ailleurs (Sénégal, France, États-Unis…).

Une entreprise fondée par des Guinéens mais sans aucune activité en Guinée n'est pas recensée dans cette version.

## Critères d'une startup (catégorie `startup`)

Les **trois** critères suivants sont requis :

| Critère | Ce qu'on vérifie |
|---|---|
| Innovation | Produit, service, modèle ou usage de la technologie qui se distingue de l'offre existante sur son marché. |
| Ambition de croissance reproductible | Le modèle peut servir beaucoup plus de clients sans hausse proportionnelle des coûts (logiciel, plateforme, réseau, produit standardisé). |
| Activité identifiable | Au moins une preuve d'activité : produit accessible, clients, chiffre d'affaires, recrutements, partenariats. |

Le statut d'entreprise (âge, taille, levée de fonds) n'est **pas** un critère. Une entreprise de 12 ans peut rester recensée si elle remplit ces critères ; une entreprise qui a levé des fonds n'est pas automatiquement une startup.

## Catégorie `projet_precoce`

Projet qui remplit les critères d'innovation et d'ambition mais **sans activité identifiable** (idée, prototype non diffusé, lauréat de concours sans lancement). Ces projets peuvent figurer dans le référentiel pour suivre leur évolution, mais :

- ils ne sont jamais comptés dans le nombre de startups ;
- ils passent en catégorie `startup` dès qu'une preuve d'activité est vérifiée (événement enregistré).

## Exclus du registre

| Type | Raison |
|---|---|
| PME traditionnelles (commerce, BTP, restauration, services classiques) | Pas d'innovation ni de croissance reproductible. |
| Associations, ONG, fondations | Pas de modèle entrepreneurial. |
| Projets étudiants et travaux académiques | Pas d'entreprise constituée ni d'activité. |
| Filiales de groupes étrangers | Pas une création locale (elles peuvent figurer comme `organisations`). |
| Freelances et agences de prestation sur mesure | Activité non reproductible. Cas limite : une agence qui édite aussi un produit peut être recensée pour ce produit. |
